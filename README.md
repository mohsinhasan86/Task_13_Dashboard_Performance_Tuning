## 🎯 Objective

The objective of this task was to improve dashboard and query performance so that the dashboard remains fast and responsive as the amount of data grows.

The project focused on measuring baseline query performance, identifying query execution behavior, applying optimization techniques, and measuring performance again after optimization.
